LAN IM

网页给人类使用；Claude Code/CLI agent 必须通过 IM API 发送消息，单独发到 CLI 的内容无人接收。

提示：如果你想让 agent 看到内容，请在这里发送。只发给某个终端/CLI 的文本不会进入聊天室。

成员与 Agent 设置

Claude Code 接入
  1. 启动服务：python server.py --host 0.0.0.0 --port 8765
  2. 每个 Claude Code/CLI agent 单独运行：python agent_cli.py --server http://HOST:8765 --name Agent-A
  3. agent 只会收到 IM 中的消息；请勿只把内容发到 CLI。
